# ============================================================
# Math LLM — Python dependencies
# ============================================================
# Every package below is actually imported somewhere in the codebase
# (verified: `grep -rhoE "^(import|from) [a-zA-Z0-9_]+" *.py`). Earlier
# versions of this file also listed scipy, seaborn, tensorboard, tqdm,
# pyyaml, jsonlines, jupyter, ipywidgets, colorlog, and tabulate — none of
# which are imported anywhere. They were pure dead weight that only added
# surface area for exactly the kind of Colab version conflict this file
# is trying to avoid, so they've been removed.
#
# torch/numpy/matplotlib are pre-installed in every Colab runtime, already
# matched to its CUDA driver. We deliberately use a MINIMUM version bound
# (">=") rather than an exact pin ("==") so `pip install -r requirements.txt`
# is satisfied by whatever Colab already has and never tries to
# reinstall/downgrade it — an exact pin to an old version (e.g. torch==2.2.2)
# will hard-fail once Colab's Python/CUDA build no longer publishes wheels
# for that old version, which is exactly what happened before this fix.

# Core deep-learning stack
torch>=2.2

# Dataset access
# The real dataset (DeepMind Mathematics Dataset, Saxton et al. 2019) is
# downloaded directly from its official static-file source
# (storage.googleapis.com) using only the Python standard library
# (urllib, tarfile) — see dataset.py. No HuggingFace `datasets` /
# `huggingface_hub` dependency is needed.

# Numerics
numpy>=1.24

# Training-curve plots (train.py / the notebook degrade gracefully if
# this is somehow missing, but Colab always has it)
matplotlib>=3.7
